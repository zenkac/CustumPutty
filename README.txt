EquipLink 1.8.2 — Windows 설비 터미널 · FTP · SSH Browser
=====================================================

업데이트
--------
기존 EquipLink를 종료하고 ZIP의 압축을 푼 뒤 EquipLink.exe를 실행하세요.
설비·FTP 사이트맵·저장된 로그인 정보·테마를 그대로 읽습니다.
settings.json을 삭제하거나 다시 가져올 필요가 없습니다.

1.8.2 화면 정리 · X 서버 상태 표시
----------------------------------
- 상단 왼쪽 [터미널 | FTP]에서 현재 작업 화면이 항상 강조됩니다. 눌러서 전환합니다.
- 시작 화면 오른쪽 [X11 / GUI 준비 상태]에서 X 서버(Xming) 실행 여부, X 서버 파일,
  DISPLAY 번호, PC IP, 자동 실행 설정을 한눈에 확인하고 [Xming 시작]을 누를 수 있습니다.
- 하단 오른쪽에 "● X 서버 실행 중 · :0" / "○ X 서버 꺼짐 · :0"이 표시됩니다.
  클릭하면 Xming 시작 · 다시 확인 · X 서버 설정 · 도움말 메뉴가 열립니다.
- 선택한 설비 카드에 X11 방식(SSH 전달 / 직접 PC IP)과 자동 로그인 여부가 표시됩니다.
- 설비 설정 창을 연결 / 로그인 / X11·GUI / 기타로 나눴습니다. X11 / GUI 사용을 끄면
  관련 항목이 비활성화되고, 선택한 연결 방식에 맞는 설명이 나타납니다.
- Xming 설정 창을 X 서버 / 디스플레이·네트워크 / 화면·터미널로 나눴습니다.
  맨 위 [상태 확인]으로 X 서버 응답을 확인하고, 선택한 PC IP 버튼이 강조됩니다.
- 창 제목에 실제 버전이 표시됩니다. FTP 사이트맵 검색창에 안내 문구가 생겼습니다.
- 기능 동작과 저장 형식은 1.8.1과 같습니다. 기존 설정을 그대로 사용합니다.

1.8.1 FTP 서버 파일 삭제 호환성 개선
------------------------------------
- 현재 폴더의 파일을 삭제할 때 서버 최상위/상위 폴더의 목록 권한까지 요구하지 않습니다.
- 삭제할 파일이 있는 폴더를 확인한 뒤 파일명으로 삭제합니다. 전체 경로를 사용하는
  삭제 명령을 거부하는 구형 FTP 서버도 지원하며, 작업 후 원래 경로로 돌아옵니다.
- 현재 목록의 일부 항목을 해석하지 못해도 이름과 종류가 확인되는 선택 파일은 삭제합니다.
  선택한 폴더 전체를 삭제할 때는 내부 목록이 완전해야 하며, 링크/경로 이탈은 계속 차단합니다.
- 실패 시 작은 창에 실패 단계·대상 경로·FTP 코드가 표시됩니다. [오류 내용 복사]로 복사합니다.
  삭제 완료가 확인된 항목 수를 구분합니다. 연결이 끊기면 새로고침해 실제 파일 상태를 확인하세요.
- 영구 삭제 확인창, 취소 기본값, 검색 결과/다중 선택 범위와 기존 UI는 유지합니다.

1.8.0 FTP 탐색기 · 자유로운 좌우 배치 · 양방향 드래그
----------------------------------------------------
- [⇄ 좌우 바꾸기]로 내 PC와 서버 위치를 바꿉니다. 연결·경로·선택은 유지되고 배치는 저장됩니다.
- [한 창 보기]로 선택한 위치를 넓게 봅니다. 폴더 영역의 [내 PC] / [FTP 서버]로 전환하며,
  [두 창 보기]로 돌아오면 양쪽 창이 다시 표시됩니다. 터미널 크기는 바뀌지 않습니다.
- 내 PC와 서버 폴더 트리에서 폴더를 선택하거나, 주소창에 경로를 직접 입력해 이동합니다.
- Windows 파일 종류 아이콘을 사용합니다. [목록]에서 이름·크기·유형·수정한 날짜를 클릭해
  정렬 방향을 바꾸고, 열 제목의 오른쪽 경계선을 끌어 너비를 조절할 수 있습니다.
  좁은 창에서는 가로 스크롤로 나머지 열을 확인합니다. 폴더는 항상 먼저 표시합니다.
- 앱의 내 PC 창 ↔ 서버 창 사이로 파일·폴더를 끌어 복사합니다. 여러 항목도 지원합니다.
  빈 곳이나 일반 파일 위에 놓으면 현재 폴더로, 폴더 위에 놓으면 그 폴더 안으로 전송합니다.
  놓기 전에 목적지와 업로드/다운로드 방향을 표시합니다. 좌우를 바꿔도 같은 방식입니다.
- 원본은 그대로 남습니다. 중복 파일은 작은 팝업에서 덮어쓰기·건너뛰기·취소를 선택합니다.
  앱 안의 드래그 전송도 전송창의 진행률·취소·히스토리에 반영됩니다.
- Windows 탐색기로 끌어내는 기능은 기존처럼 일반 파일을 지원합니다. 폴더는 앱의 내 PC 창에
  놓거나 다운로드 버튼을 이용하세요. 터미널 FTP 명령 도우미에는 드래그로 전송하지 않습니다.

1.7.0 FTP 검색 · 다중 선택 · 삭제 · 경유 설비 명령 도우미
------------------------------------------------------
- 내 PC와 서버의 경로 아래 [검색]에 파일명 일부를 입력하면 현재 폴더만 필터링합니다.
  한글과 영문 대소문자 구분 없는 포함 검색을 지원합니다. 하위 폴더를 재귀 검색하지 않습니다.
  Esc 또는 ×로 검색을 지우며 다른 폴더로 이동하면 검색을 초기화합니다.
- Ctrl+클릭으로 개별 추가/해제, Shift+클릭으로 연속 선택, Ctrl+A로 보이는 항목 전체 선택.
  목록의 빈 공간에서 드래그하면 사각형에 닿은 파일을 여러 개 선택합니다.
  Ctrl+드래그는 선택 반전, Shift+드래그는 추가 선택입니다. 아이콘/목록 보기 모두 지원합니다.
  이미 선택된 파일 아이콘에서 드래그하면 기존 파일 전송 동작을 유지합니다.
- 검색으로 숨겨진 항목은 선택에서 제외합니다. 하단에 표시 수 / 전체 수와 선택 수를 보여줍니다.
- [삭제], Delete 키 또는 우클릭 메뉴에서 선택 파일·폴더를 삭제합니다.
  작은 확인창에 대상 위치·파일명과 '휴지통을 거치지 않는 영구 삭제' 경고를 표시합니다.
  기본 선택과 Esc는 취소입니다. 폴더 내부도 삭제되므로 내용을 확인한 뒤 진행하세요.
  전송 대기/진행 중에는 삭제를 차단합니다. 링크·연결점이나 불완전 목록이 발견되면 중단하며,
  폴더 내부를 포함해 한 번에 최대 10,000개 항목을 처리합니다.

경유 설비2 ↔ 서버: 터미널 FTP 사용 순서
---------------------------------------
PC → Telnet 설비1 → Telnet 설비2로 들어간 경우, PC에서 설비2의 FTP에 직접 접속할 수 없어도
설비2에서 'ftp -i 서버IP'를 실행하는 기존 방식을 명령 도우미로 지원합니다.
이 기능은 설비2 폴더를 PC에서 직접 탐색하는 기능이 아닙니다.

1. 평소처럼 터미널에서 설비2까지 접속합니다.
2. FTP 화면에 파일을 중계할 서버를 연결합니다.
3. 내 PC 창 상단의 [내 PC]를 열고 해당 탭의 [터미널 FTP · 설비명]을 선택합니다.
   탭 이름은 처음 접속한 설비1 이름입니다. 실제 현재 위치가 설비2인지 터미널에서 확인하세요.
4. [FTP 접속 명령 준비] → 해당 터미널의 명령 입력창에 'ftp -i 서버IP'가 준비됩니다.
   셸 프롬프트에서 [실행 ↵] 또는 Ctrl+Enter로 실행하고 ID·비밀번호는 터미널에서 직접 입력하세요.
   이미 ftp> 안에 있다면 접속 명령을 다시 실행하지 않습니다.
5. FTP 화면으로 돌아와 설비 폴더(lcd), 서버 폴더(cd), binary 명령을 각각 준비·실행합니다.
   cd/lcd 성공 여부와 현재 경로는 실제 터미널에서 확인하세요.
6. 올릴 파일은 파일명이나 *.log 같은 패턴을 입력하고 [설비 → 서버 put/mput]을 사용합니다.
   받을 파일은 서버 창에서 검색·선택한 뒤 [서버 → 설비 준비]를 누릅니다.
   먼저 도우미의 서버 폴더(cd)를 실행한 후 [서버 → 설비 get/mget]을 사용하세요.
   일반 파일 더블클릭도 받을 파일명을 도우미에 준비합니다. 폴더 더블클릭은 서버 폴더 이동입니다.
7. 같은 이름의 대상 파일이 있으면 CLI가 덮어쓸 수 있다는 확인창이 표시됩니다.
   준비된 명령은 자동 전송/실행하지 않습니다. 프롬프트를 확인한 뒤 명령 입력창에서 실행하세요.
8. 전송 완료는 설비2의 FTP 터미널에서 확인합니다. 이후 [내 PC]로 전환해 서버 파일을 내려받습니다.

이 모드의 진행률·전송 이력·실제 중복 파일 여부는 앱의 FTP 전송 대기열에 연동되지 않습니다.
설비 파일 목록, 로그인, 전송 결과는 현재 터미널에서 확인해야 합니다.
도우미는 일반 파일명과 단순 패턴을 지원하며, 폴더 전체·특수 문자가 포함된 이름은 직접 입력하세요.
Windows 탐색기와의 드래그는 선택 모드와 관계없이 항상 내 PC ↔ FTP 서버 전송입니다.
일반 [내 PC] 모드의 중복 파일 확인·더블클릭 다운로드·기존 전송 대기열은 그대로 동작합니다.
기존 Telnet 원격 폴더용 eval/셸 연동은 추가하지 않습니다. SSH Browser는 기존 SFTP 방식입니다.
명령 참고: https://www.gnu.org/software/inetutils/manual/html_node/Ftp-commands.html

1.6.4 FTP 파일 더블클릭 다운로드
--------------------------------
- 서버 쪽 파일을 왼쪽 버튼으로 더블클릭하면 '내 PC'에 현재 열린 폴더로 다운로드합니다.
  아이콘 보기와 목록 보기 모두 지원하며, 여러 항목을 선택했어도 더블클릭한 파일 하나만 받습니다.
- 폴더를 더블클릭하면 기존처럼 그 폴더를 엽니다.
- 같은 이름의 PC 파일이 있으면 작은 팝업에서 덮어쓰기 / 건너뛰기 / 취소를 선택합니다.
- 다운로드는 기존 전송 대기열과 히스토리에 기록되며 완료 시 내 PC 목록을 갱신합니다.
- 기존 다운로드 버튼의 여러 파일·폴더 전송과 탐색기 드래그 전송은 유지합니다.

1.6.3 비밀번호 저장 표시와 자동 로그인
--------------------------------------
- 설비 편집에서 ID·비밀번호를 입력하면 저장 옵션이 자동으로 켜집니다.
  [설비 저장]을 누른 뒤 목록에서 더블클릭하면 저장된 정보로 자동 로그인합니다.
- 다시 편집하면 비밀번호 칸에 마스킹된 '저장됨' 표시가 나옵니다.
  실제 비밀번호를 편집창에 다시 풀어 넣지 않으며, 비워 두고 저장해도 기존 값은 유지됩니다.
- [더블클릭 접속 시 저장한 ID · 비밀번호로 자동 로그인]을 끄면
  비밀번호는 보관하면서 수동 로그인할 수 있습니다.
- Telnet은 최초 login / Login as / Username / User name / User 및 Password 안내를
  확인해 ID·비밀번호와 Enter를 한 번씩 입력합니다. 잘못된 비밀번호를 반복 시도하지 않습니다.
  수동 키 입력, 로그인 메뉴 사용, 셸 화면 감지 또는 90초 경과 시 자동 입력을 중단합니다.
  특수한 로그인 안내, OTP, 비밀번호 변경은 터미널에서 직접 진행하세요.
- SSH는 PuTTY의 인증 단계에 저장된 비밀번호를 전달합니다.
  최초 서버 키 확인과 개인 키 암호는 기존 PuTTY 화면에서 직접 진행합니다.
  OTP 등 다단계 인증을 사용한다면 설비 편집에서 자동 로그인을 끄고 접속하세요.
  비밀번호가 틀리면 SSH 인증을 중단합니다. 설비의 비밀번호를 고치고 재연결하세요.
- 로그인 정보는 같은 Windows 계정에서 암호화하여 보관합니다.
  다른 PC/계정에서 가져왔거나 읽을 수 없는 비밀번호는 다시 입력하라는 상태를 표시합니다.
- 이전 버전에서 저장된 ID·비밀번호도 자동 로그인에 사용합니다.
  실제로 저장되지 않았던 설비는 편집에서 한 번 입력하고 저장해 주세요.
- 터미널 크기·분할·FTP·SSH Browser는 유지합니다. 원격 폴더용 셸 명령을 삽입하지 않습니다.

1.6.2 작은 덮어쓰기 팝업
-----------------------
- FTP 덮어쓰기 확인창을 폭 480 DIP의 작은 팝업으로 바꿨습니다.
  고정된 큰 높이 대신 내용에 맞춰 높이를 정하고 앱 창 중앙에 표시합니다.
- 대상이 내 PC인지 서버인지 표시하고 파일명과 경로를 간결하게 보여줍니다.
  긴 파일명/경로는 줄임표로 표시하며 마우스를 올리면 전체 내용을 확인할 수 있습니다.
- 덮어쓰기 / 건너뛰기 / 취소 선택을 유지하며 Esc로 취소할 수 있습니다.
- 외부 Windows 탐색기의 자체 중복 파일 창은 Windows에서 표시합니다.

1.6.1 아이콘 / 목록 보기
-----------------------
- FTP 상단의 [아이콘] [목록] 버튼으로 원하는 보기를 바로 선택합니다.
  선택한 버튼을 강조 표시하며 내 PC와 서버 목록에 함께 적용합니다.
- [아이콘]: 파일 형식과 폴더를 큰 아이콘으로 표시합니다.
- [목록]: 이름 · 크기 · 수정한 날짜를 한 줄씩 표시합니다.
- 마지막 선택은 자동 저장되며 다음 실행에서도 유지됩니다.
  보기를 바꿔도 현재 경로, 선택 파일과 FTP 연결은 유지됩니다.
  두 보기에서 드래그 전송과 업로드/다운로드를 사용할 수 있습니다.

1.6 FTP: Windows 탐색기와 드래그 전송
-----------------------------------
- 외부 Windows 탐색기에서 파일/폴더를 골라 FTP 서버 목록에 놓으면 업로드합니다.
  빈 곳은 현재 서버 경로, 폴더 아이콘 위는 해당 폴더에 전송합니다.
  여러 파일과 하위 폴더 업로드를 지원합니다.
- 서버 일반 파일을 골라 Windows 탐색기에 열어 둔 폴더로 끌면 다운로드합니다.
  여러 파일을 함께 선택할 수 있고 서버 원본은 유지됩니다.
  폴더 전체를 PC로 내려받을 때는 내 PC 경로를 정하고 [다운로드] 버튼을 이용하세요.
  서버 폴더/심볼릭 링크를 외부 탐색기로 끌어내는 기능은 이번 버전에 포함하지 않습니다.
- [아이콘] [목록] 버튼으로 두 가지 보기를 전환합니다.
  파일 형식 표시, 폴더 아이콘, Ctrl/Shift 다중 선택을 지원합니다.
- 앱 내부 업로드/다운로드에서 중복 파일이 있으면 파일별로
  [덮어쓰기 / 건너뛰기 / 취소]를 선택합니다. 덮어쓰기를 눌러야 기존 파일을 교체합니다.
  건너뛰기는 해당 파일을 제외하고 나머지를 계속합니다. 취소는 해당 전송 작업을 취소합니다.
  이미 완료된 다른 파일은 유지됩니다.
- 외부 탐색기로 끌어내릴 때의 중복 파일 확인은 Windows 탐색기가 담당합니다.
  같은 이름이 있으면 탐색기의 교체/건너뛰기 선택창에서 결정합니다.
- 외부 드래그는 Windows가 저장을 처리하고 앱에는 [전달 완료]로 기록됩니다.
  최종 PC 경로는 앱에 전달되지 않아 기록에는 [Windows 탐색기]로 표시합니다.
  외부 드래그는 앱의 전송 대기열에 넣지 않습니다.
- 내려놓은 파일을 임시 저장소로 완전히 수신한 뒤 Windows에 전달하고 임시 파일을 정리합니다.
  대용량 파일은 수신하는 동안 기다릴 수 있으며 로컬 디스크 여유 공간이 필요합니다.
- 탐색기와 EquipLink를 같은 Windows 권한 수준으로 실행하세요. 관리자 권한은 필요하지 않습니다.
- 전송 중 새 중복 파일이 생겨도 완료 전에 확인합니다. 다만 FTP에는 모든 서버에 공통인
  원자적 '덮어쓰지 않는 이름 변경'이 없어, 최종 확인 직후 다른 프로그램이 같은 이름을
  만드는 서버 측 경합까지 막을 수는 없습니다.

1.6 SSH Browser (SFTP)
---------------------
- 이전 셸 명령 주입 방식과 경로 연동 버튼/코드를 제거했습니다.
  이전 버전에서 연동을 시도한 터미널은 새 버전에서 다시 접속해 사용하세요.
  폴더 조회를 위해 터미널에 eval, ls, cd 등의 명령을 보내지 않습니다.
- SSH 설비 연결 → 왼쪽 [SSH Browser] → [SFTP 연결] 순서로 사용합니다.
  저장한 설비 ID·비밀번호를 사용할 수 있고 시작 경로를 지정할 수 있습니다.
  시작 경로가 비어 있으면 서버가 알려 주는 로그인 홈 폴더를 엽니다.
- 비밀번호, 설비에 지정한 개인 키(PuTTY PPK 포함), 추가 인증 입력을 지원합니다.
  개인 키 암호는 저장하지 않습니다. SFTP 로그인 창에서 ID·비밀번호 저장 여부를 선택합니다.
- SSH 서버의 SFTP 기능이 허용되어 있어야 합니다. 기본 포트는 SSH와 같은 22입니다.
  SSH 터미널은 접속되어도 서버에서 SFTP를 막으면 파일 탐색은 사용할 수 없습니다.
  별도 SFTP 연결이므로 PuTTY 저장 세션의 프록시/점프 호스트 설정은 상속하지 않습니다.
- 최초 연결 시 서버 키의 SHA-256 지문을 확인합니다. 이후 키가 바뀌면 연결을 중단합니다.
  PuTTY 터미널과 SFTP의 서버 키 확인/저장은 각각 관리합니다.
- 폴더 한 번 클릭, 주소 입력 후 Enter, 상위 폴더(↑), 새로고침(↻)으로 탐색합니다.
  숨김 항목 포함 처음 10,000개까지 표시하며 제어 문자가 있는 이름은 제외 수를 알립니다.
  SFTP 파일명은 UTF-8을 사용합니다.
- SFTP 탐색 경로와 터미널 작업 경로는 각각 유지됩니다.
  폴더 클릭으로 터미널의 cd가 실행되거나 터미널 경로를 자동으로 따라가지 않습니다.
  서버 셸 설정을 변경하지 않습니다.
- 탭/분할별 연결과 경로를 유지합니다. 탭 종료·재연결 시 해당 SFTP 연결도 닫힙니다.
  설비 목록/SSH Browser 전환과 기존 터미널 작업 크기는 유지됩니다.
- 일반 파일 업로드·다운로드, 새 폴더, 현재 탭의 전송 기록 50건도 이용할 수 있습니다.
  SFTP 중복 파일은 보호하므로 다른 저장 이름을 선택하세요.
  위의 덮어쓰기 선택 및 외부 탐색기로 끌어내기는 FTP 화면의 기능입니다.

Telnet에서는?
-------------
Telnet 자체에는 SFTP 같은 파일 탐색 채널이 없습니다. 터미널의 ls/pwd로 폴더를 확인할
수는 있지만 Telnet 접속만으로 SSH Browser를 사용할 수는 없습니다.
Telnet 탭에서는 파일 탐색 안내만 표시합니다. 설비에 FTP가 허용되면 상단 [FTP]에서
별도로 연결해 파일을 볼 수 있습니다. Telnet(23)만으로 FTP(21)나 SSH(22)가 열리지는 않습니다.

1.4.1 FTP 파일명·연결 대기 화면 수정
----------------------------------
- 일부 파일 이름이나 목록 형식을 해석하지 못해도 정상 파일·폴더 목록은 계속 표시합니다.
  제외된 항목 수는 서버 목록 아래에 표시합니다. ./이름, 현재 폴더의 절대 경로로 반환하는
  구형 서버 목록과 Linux에서 사용하는 역슬래시 포함 이름도 표시할 수 있습니다.
  Windows에 저장할 수 없는 이름은 다운로드할 때 별도로 안내합니다.
- [FTP → 접속하기] 또는 저장한 사이트 편집에서 [파일명 문자셋]을 선택합니다.
  기본값은 [자동 감지 (권장)]입니다. 서버의 UTF-8 지원 응답과 실제 경로·목록 바이트를
  확인하여 UTF-8, CP949, ISO-8859-1 순으로 손실 없는 해석을 시도합니다.
  서버가 UTF-8 지원을 알리지 않으면 첫 감지 전에는 CP949를 사용합니다.
  감지한 문자셋은 목록 아래에 표시하며, 해당 연결의 파일 전송에도 동일하게 적용합니다.
- [UTF-8로 강제 설정]과 [문자셋 직접 설정]도 사용할 수 있습니다.
  직접 지정 예: CP949, windows-1252, shift_jis 또는 지원하는 코드 페이지 번호.
  여러 인코딩으로 해석 가능한 파일 이름은 자동 감지만으로 구별할 수 없습니다.
  이름이 잘못 보이면 서버 문자셋을 직접 지정하고 다시 연결하세요.
  비ASCII 로그인 ID·비밀번호를 사용하는 구형 서버도 해당 문자셋을 직접 지정하세요.
- 1.4에서 저장한 기본 UTF-8 설정은 첫 실행 시 자동 감지로 전환합니다.
  기존 CP949/ISO-8859-1 지정값, 사이트 정보와 저장된 비밀번호는 유지합니다.
  1.4.1에서 새로 선택한 UTF-8 강제 설정은 다음 실행에도 유지합니다.
- FTP 방식은 일반 FTP(Use plain FTP), 기본 포트 21, 패시브 모드를 유지합니다.
- 서버 연결 대기·접속 오류·목록 읽기 중에도 배경이 흰색으로 바뀌지 않습니다.
  Midnight, Graphite, Nord 테마 모두 수정했으며 터미널 작업 크기는 유지합니다.
- 목록 일부가 제외되어 기존 파일과의 중복 여부를 확인할 수 없는 폴더는 업로드를 중단합니다.
  정상 항목의 탐색·다운로드는 계속 가능하며, 폴더 다운로드는 제외 항목 수를 알려줍니다.
- 업데이트: 기존 EquipLink를 종료하고 이 패키지의 EquipLink.exe를 실행하세요.
  설정 파일을 삭제하거나 다시 가져올 필요가 없습니다.

1.4 FTP 파일 전송
------------------------
- 상단 [FTP] 버튼으로 파일 전송 화면을 열고 [터미널]로 돌아옵니다.
  열려 있는 Telnet/SSH 연결과 터미널 분할 크기는 유지됩니다.
- [사이트맵 +]에서 서버 이름, IP, 포트(기본 21), ID, 비밀번호, 기본 경로를 저장합니다.
  저장한 사이트를 더블클릭하면 바로 연결합니다. [•••]에서 편집/삭제합니다.
- [접속하기]는 최근에 입력한 서버 정보를 다시 채워 줍니다.
  비밀번호 저장 체크 시 현재 Windows 계정에 묶어 DPAPI로 암호화합니다.
  다른 PC/Windows 계정으로 설정을 옮기면 비밀번호는 다시 입력해야 합니다.
- 왼쪽 서버 폴더 트리를 클릭하거나 파일 목록 위 주소창에 경로를 입력하고 Enter를 누릅니다.
  폴더 더블클릭, 상위 폴더(↑), F5 새로고침을 사용할 수 있습니다.
- 내 PC 파일/폴더를 선택하고 [업로드], 서버 항목을 선택하고 [다운로드]합니다.
  Ctrl/Shift로 여러 항목을 선택할 수 있으며 폴더는 하위 항목도 전송합니다.
- [새 폴더]는 현재 서버 경로에 폴더를 만듭니다. 내 PC 목록의 우클릭 메뉴에서도 폴더를 만듭니다.
- [전송창]에서 대기열·진행률·히스토리를 확인하고 선택/전체 전송을 취소합니다.
  완료/실패/취소 내역은 최근 500개까지 저장됩니다. 대기열은 앱 재시작 시 재개되지 않습니다.
- 동일한 이름의 파일은 덮어쓰기/건너뛰기/취소 확인창에서 결정합니다.
- 개별 파일은 임시 파일에 전송한 다음 완료 시 원래 이름으로 바꿉니다.
  폴더 전송 중 취소/실패하면 이미 완료된 파일은 유지됩니다. 심볼릭 링크/연결점은 건너뜁니다.
  서버가 끊겨 정리하지 못한 .equiplink-*.part 파일이 남을 수 있습니다.
  서버가 이름 변경을 지원하지 않으면 업로드가 실패하며 기존 파일은 삭제하지 않습니다.
- FTP 화면의 폴더 영역에서 [내 PC] / [FTP 서버]를 선택해 각각의 경로를 탐색합니다.
  터미널 왼쪽 [SSH Browser]는 별도 SFTP 연결로 파일을 탐색합니다.
- FTP 서버가 해당 설비에서 동작해야 합니다. Telnet(23)/SSH(22) 연결만으로 FTP가 열리지는 않습니다.
  FTP는 21번 제어 포트 외에 서버가 지정한 Passive 데이터 포트에도 접근할 수 있어야 합니다.
- 지원: 일반 FTP, EPSV/PASV, MLSD 및 UNIX/DOS LIST, 파일명 문자셋 자동 감지·직접 지정.
  FTP 화면은 FTPS, 전송 재개, 폴더 동기화를 포함하지 않습니다. SFTP는 SSH Browser에서 이용합니다.
- 기존 1.3의 설비·설정은 그대로 읽습니다. 기존 앱을 종료하고 새 EXE를 실행하세요.

1.3 포커스·테마·화면 개선
------------------------
- 새 접속 창을 취소하면 기존 터미널의 입력 포커스를 복원합니다.
- 터미널 본문을 클릭하면 해당 패널이 활성화되고 바로 입력할 수 있습니다.
- 열린 설정창·메뉴나 다른 프로그램으로 입력 포커스가 옮겨진 동안에는 터미널이 이를 가져오지 않습니다.
- 테마 3종: Midnight · 민트(기본) / Graphite · 앰버 / Nord · 블루.
- [설정 / Xming → 화면 테마]에서 선택하고 저장한 뒤 앱을 다시 열면 적용됩니다.
  메뉴·설정창·PuTTY 배경·텍스트·커서·ANSI 색상을 함께 변경합니다.
  테마를 바꾸려고 실행 중인 설비 연결을 자동 종료하지 않습니다.
- 분할 아이콘은 선명한 벡터로 교체하고 탭·설비 목록·버튼을 다듬었습니다.
- 터미널 공간을 확보한 기존 레이아웃과 분할 크기는 유지합니다.
- 추가 이미지·테마 라이브러리 설치 없이 색상 설정만 사용합니다.

설정창 및 로그인 정보
------------------------
- 설정·설비 편집·도움말 창의 배경, 제목, 입력창을 본 화면과 같은 다크 톤으로 통일했습니다.
- 설비 편집에서 로그인 ID와 비밀번호를 저장할 수 있습니다.
- 비밀번호 저장은 선택 사항이며 Windows DPAPI로 현재 Windows 계정에 묶어 암호화합니다.
- 저장한 설비는 더블클릭 시 자동 로그인합니다. 수동 입력은 상단 [로그인] 또는 패널 [•••]에서 선택합니다.
  수동 메뉴는 해당 로그인 프롬프트에서 사용하고 Enter를 직접 누릅니다.
- 기존 1.0 / 1.1 / 1.2의 설비와 설정은 그대로 사용할 수 있습니다.

작업공간
------------------
- 상단 연결 폼과 하단 상시 명령 패널을 접어 터미널 공간을 확장했습니다.
- 상단 분할 버튼: 단일 / 좌우 2분할 / 상하 2분할 / 4분할.
- 세션을 여러 개 열고 분할을 선택하세요. 빈 패널에서는 빠른 접속으로 채웁니다.
- 열린 탭 중 현재 보이지 않는 탭을 선택하면 활성 패널만 교체됩니다.
- 분할 경계 드래그로 비율 조정. [••• → 분할 비율 초기화]로 동일 크기 복원.
- 패널 제목 더블클릭 또는 확대 버튼으로 한 패널 확대/복원.
- [☰]로 설비 목록을 접고, [집중]으로 메뉴/사이드바/상태줄을 숨깁니다.
- 모든 패널은 독립 연결입니다. 입력과 GUI 명령은 선택한 터미널에만 전송됩니다.
- PuTTY 배경/기본색/커서/ANSI 16색을 앱 테마와 통일했습니다.
- 스크롤바를 숨겨 작업 폭을 확보했습니다. 마우스 휠과 Shift+PageUp/PageDown은 유지됩니다.
- 기존 1.0 설비/설정 파일을 그대로 읽습니다. 기존 버전 종료 후 새 EXE를 실행하세요.

터미널 제목 [•••]에 재연결·창 분리·명령 모음·GUI 도구를 모았습니다.
분리한 외부 PuTTY 창에서는 EquipLink 단축키를 가로채지 않습니다.

실행
----
배포 ZIP의 압축을 푼 뒤 같은 폴더의 EquipLink.exe를 실행하세요.
원본 작업 폴더에서는 artifacts\portable-v1.8.2\EquipLink.exe에 있습니다.
설치와 별도 .NET 런타임이 필요 없는 Windows x64 프로그램입니다.
Windows 10/11 x64를 대상으로 만들었습니다. 관리자 권한은 필요하지 않습니다.
공식 PuTTY 0.85 엔진이 실행 파일에 포함되어 있습니다.
Xming 또는 VcXsrv는 기존에 설치된 프로그램을 사용합니다.

처음 한 번 설정
---------------
1. 왼쪽 아래 [설정 / Xming] 또는 상단 [••• → 설정]을 누릅니다.
2. Xming.exe와 XLaunch.exe 경로를 확인합니다.
   일반적인 설치 경로는 자동으로 찾습니다. 다른 위치이면 [찾기]로 지정합니다.
3. 평소 사용하던 .xlaunch 파일을 지정합니다.
   기존 파일이 없으면 Xming.exe만 지정해도 Multiple windows + Clipboard로 실행합니다.
   기존 .xlaunch 파일의 접근 제어, 디스플레이 번호, 네트워크 설정을 그대로 사용합니다.
4. [설비에 연결할 때 Xming을 자동으로 실행]을 켭니다.
5. PC IP는 기본적으로 설비와 연결된 네트워크 경로에서 자동으로 정합니다.
   유선망·VPN 등 여러 IP를 사용할 때는 목록에서 올바른 PC IP를 선택합니다.
6. 디스플레이 번호는 평소 :0.0을 쓴다면 0으로 둡니다.

일상적인 사용
--------------
- 새 설비: 상단 [빠른 접속]에서 IP 입력 → Telnet(기본) 또는 SSH 선택 → 연결.
- 자주 쓰는 설비: 왼쪽 라이브러리의 [+] 또는 빠른 접속의 [이 설비를 목록에 저장] → 이름·IP 저장 → 목록 더블클릭.
- ID·비밀번호 저장: 설비 우클릭 → 편집 → 로그인 ID·비밀번호 입력 → 자동 로그인 체크 → 설비 저장.
- 목록의 설비를 더블클릭하면 자동 로그인합니다. 수동 로그인할 때는 [로그인 → 저장한 ID 입력] 후 Enter를 누릅니다.
  비밀번호 프롬프트에서는 [로그인 → 저장한 비밀번호 입력] 후 Enter를 누릅니다.
  SSH는 저장한 ID를 접속 설정에 반영하므로 ID 입력 단계가 생략될 수 있습니다.
- 터미널에서 로그인한 다음 [새 xterm 열기]를 누릅니다.
  Telnet 기본 명령: xterm -display PC_IP:0.0 &
- 설비 설정에 별도 테스트 GUI 명령을 저장하면 [테스트 GUI]로 실행할 수 있습니다.
- 같은 설비 터미널을 하나 더 열려면 터미널 제목의 [••• → 같은 설비에 새 접속]를 누릅니다.
- 터미널 제목의 [••• → 재연결]은 현재 세션을 종료한 후 다시 접속합니다.
- 터미널 제목의 [••• → 별도 창으로 분리]는 해당 PuTTY 터미널을 별도 창으로 옮깁니다.
- Xming 시작과 설정은 로컬 PC에서 수행합니다. 설비에 프로그램을 설치하지 않습니다.

Telnet과 SSH의 X11 차이
-----------------------
Telnet 기본 모드는 PC IP를 지정하는 직접 X11 연결입니다.
설비에서 PC의 TCP 6000 + 디스플레이 번호로 접근할 수 있어야 합니다.
X 서버의 설비 접근 허용 및 기존 방화벽 환경이 필요합니다.
[설비 X11 허용]은 xhost.exe가 있을 때 선택한 설비 IP만 X 서버에 허용합니다.
앱은 Windows 방화벽을 변경하거나 모든 호스트 접근(-ac)을 자동으로 켜지 않습니다.

SSH 자동 모드는 PuTTY X11 forwarding을 사용하며 xterm & 명령을 보냅니다.
이때 SSH가 만든 DISPLAY를 PC IP로 덮어쓰지 않습니다.
SSH에서도 xterm -display PC_IP:0.0 & 방식을 쓰려면 설비 설정에서
[GUI 연결 방식 → 직접 · PC IP로 연결]을 선택하세요.
SSH X11 forwarding은 설비 SSH 서버의 허용 설정에 따라 동작합니다.
SSH의 디스플레이 번호를 바꾸면 해당 세션은 다시 연결하세요.

편의 기능
---------
설비 검색 / 그룹 / 즐겨찾기 / 다중 탭 / 최근 접속 기록 / PuTTY 세션 가져오기
Telnet 23 및 SSH 22 기본 포트 / UTF-8·CP949·ISO-8859-1 / SSH PPK 개인 키
명령 모음 / 설비별 메모 / 선택적 터미널 출력 로그 / 설정 JSON 백업·병합 가져오기
20,000줄 기본 스크롤 보관 / 글자 크기 설정 / 접속 포트 응답 확인

PuTTY에서 드래그하면 복사됩니다. Shift+Insert로 붙여넣을 수 있습니다.
앱의 [입력만]은 한 줄 명령을 입력하며 Enter를 보내지 않습니다.
[실행], [새 xterm 열기], [테스트 GUI]는 즉시 명령을 보냅니다.
로그인을 마치고 셸 프롬프트가 준비된 뒤 사용하세요.
명령 모음에서 고른 명령은 입력란에만 준비되며 자동 실행되지 않습니다.
설비 프로필의 연결 설정은 새 접속부터 적용됩니다.
공통 Xming 경로와 PC IP 변경은 열려 있는 Telnet 세션의 다음 GUI 실행에도 적용됩니다.

저장 위치와 종료
----------------
%LOCALAPPDATA%\EquipLink\settings.json   설비·공통 설정·명령·최근 기록
%LOCALAPPDATA%\EquipLink\settings.json.bak   직전 설정 백업
%LOCALAPPDATA%\EquipLink\sftp-host-keys.json   SFTP 서버 키
%LOCALAPPDATA%\EquipLink\drag-cache\     외부 드래그 임시 파일
%LOCALAPPDATA%\EquipLink\logs\           선택한 세션의 출력 로그
%LOCALAPPDATA%\EquipLink\bin\putty-0.85\ 내장 PuTTY 실행본과 MIT 라이선스

비밀번호는 settings.json 및 직전 설정 백업에 암호화된 값으로 저장합니다.
앱은 비밀번호를 클립보드·실행 인자·PuTTY 저장 세션·명령 입력란에 넣지 않습니다.
SSH 비밀번호는 현재 Windows 사용자만 접근하는 메모리 파이프로 PuTTY에 전달하며 평문 임시 파일을 만들지 않습니다.
가져온 PuTTY 세션의 강제 로컬 에코는 자동 모드로 바꿔 비밀번호 프롬프트의 표시 설정을 따릅니다.
자동 로그인은 최초 인증 단계에서 비밀번호와 Enter를 전송합니다. 로그인 메뉴를 통한 수동 입력은 Enter를 직접 누릅니다.
비밀번호 프롬프트가 준비되었는지 확인한 뒤 사용하세요.
FTP/SFTP는 연결 시 입력하거나 저장한 비밀번호로 인증합니다. 로그인 ID는 일반 설정 값으로 저장됩니다.
비밀번호 필드가 비어 있으면 기존 값을 유지합니다. 저장 체크를 해제하고 저장하면 제거됩니다.
설비 IP·포트·접속 방식·ID를 바꾸면 비밀번호를 다시 입력하거나 저장을 해제해야 합니다.
Windows 계정이 바뀌거나 다른 PC로 옮기면 저장된 비밀번호를 사용할 수 없으므로 다시 입력하세요.
설정 백업 내보내기는 비밀번호를 제외하며, 가져오기에서도 비밀번호 값을 제외합니다.
SSH 호스트 키 확인은 PuTTY의 기본 확인 절차를 사용합니다.
기존 PuTTY 저장 세션은 수정하지 않습니다. 앱이 만든 임시 세션만 종료 시 정리합니다.
프로그램을 종료하면 열려 있는 세션의 종료를 확인합니다.
Xming과 이미 띄운 GUI 작업 환경은 앱에서 강제로 종료하지 않습니다.
SSH 전달로 연결한 GUI는 SSH 연결 종료 시 함께 끊길 수 있습니다.
백업에는 IP, 설비 메모, 명령과 파일 경로가 포함됩니다.

문제 해결
---------
터미널 접속 실패: [포트 확인]으로 IP/포트 응답을 확인합니다.
GUI 창이 없음: Xming 실행, PC IP, XLaunch 설정, 설비→PC 경로를 확인합니다.
XLaunch 설정 Display 번호와 앱 설정 Display 번호가 일치해야 합니다.
탭 삽입이 조직 PC 정책/디스플레이 환경에서 제한되면 설정에서 [별도 창 사용]을 켭니다.
알 수 없는 오류: 데이터 폴더의 startup-error.txt / errors.log를 확인합니다.
FTP 한글 이름이 잘못 보임: [파일명 문자셋 → 자동 감지]로 다시 연결합니다.
서버 문자셋을 알고 있으면 [문자셋 직접 설정]에서 CP949 등을 지정할 수 있습니다.
목록에 제외 항목 안내가 있음: 정상 항목은 계속 이용할 수 있습니다. 해당 서버의 문자셋과
목록 형식을 확인하세요. 모든 항목이 제외되어도 빈 폴더로 표시하지 않고 안내합니다.
SFTP 접속 실패: SSH 포트 접근, SFTP 허용 여부, ID/개인 키/비밀번호를 확인하세요.
SFTP 서버 키 변경: 관리자가 제공하는 지문과 변경 사실을 확인해야 합니다.
외부 드래그가 금지 표시: 탐색기와 EquipLink를 같은 Windows 권한 수준으로 실행하세요.

전면 창 사이의 물리 마우스 드래그 및 탐색기의 중복 파일 선택창 조작은 자동 검증하지 못했습니다.
오프스크린 검증 환경에서 Windows의 전면 창 전환이 제한되어, 전면 창의 물리 키보드 입력과
마우스 클릭에 의한 포커스 복원은 자동 검증하지 못했습니다.
실제 설비의 FTP 서버 호환성, Telnet 로그인, SSH 인증, Xming을 통한 원격 GUI 표시는
설비망 접근 정보가 없어 이 패키지 제작 과정에서 검증하지 않았습니다.
배포본의 검증결과.txt와 FTP 화면 미리보기 PNG를 참고하세요.
